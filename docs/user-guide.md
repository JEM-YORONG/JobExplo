# JobExplo - User Guide

## Getting Started
JobExplo helps you discover job opportunities with advanced search capabilities and salary insights.

## Navigation
- **Home Page**: Shows featured jobs and quick search
- **Jobs Page**: Advanced job search with filtering options
- **Job Details**: Complete job listing with application links
- **Salary Insights**: Salary comparison data
- **Companies**: Explore potential employers

## Searching Jobs
1. Use search bar on home or jobs page
2. Apply filters:
   - Location
   - Salary range
   - Experience level
   - Job type (remote, hybrid, onsite)
3. Sort results by relevance or date

## Job Details Page
Each job listing includes:
- Full job description
- Company information
- Salary range (if available)
- Required qualifications
- Application instructions
- Easy apply button (when available)

## Salary Insights
View salary trends by:
- Job title
- Location
- Experience level
- Company size

## Saving Jobs
- Click the bookmark icon to save jobs for later
- Access saved jobs from user profile
- Receive notifications for saved job updates

## Profile Management
- Update personal information
- Track application history
- Manage saved searches
- Set job alerts preferences

## Accessibility Features
- Keyboard navigation support
- Screen reader compatible
- High contrast mode
- Responsive design for mobile devices
